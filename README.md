# TCP/UDP chat

Задачи решаются строго последовательно.
1. На ПЭВМ собрать простой чат на основе двух экземпляров программы netcat. Программы должны быть запущены в разных терминалах (клиент, сервер соответственно). При передаче любой информации в stdin клиента она должна отображаться в stdout сервера и наоборот. Достаточно запустить одной ПЭВМ через localhost (127.0.0.1).
Дополнительные условия к задаче 1.
1.1. Решить задачу для случаев использования протоколов: TCP и UDP.
1.2. Сделать так, чтобы в случае обрыва соединения программы ожидали восстановления соединения. В каких случаях в этом есть смысл? (В рамках одной ПЭВМ достаточно перезапускать клиент или сервер)
1.3. Если есть возможность, проверить соединение через реальную сеть на двух ПЭВМ.
2. Написать программу TCP-клиента на Python, которая будет повторять поведение программы netcat задачи 1.
3. Вернуться к задаче 1 и заменить TCP-клиент на программу на Python, убедиться что поведение чата не изменилось.
4. Написать программу TCP-клиента на С/С++ используя сокеты, которая будет повторять поведение программы netcat задачи 1.
5. Написать программу TCP-сервера на С/С++ используя сокеты, которая будет повторять поведение программы netcat задачи 1.
Разрешено пользоваться любыми источниками информации и задавать мне уточняющие вопросы.
Результаты обсудим потом у меня на работе.
